# ca-reading — what the owner is reading, and how far into it they are

> Generated by `aw new`, then edited by hand for one week of real use. This is the
> golden fixture: the shape a domain should have after it has actually been used,
> not the shape it has the moment it is created.

## When to load

- "I read 30 pages of X today, log it"
- "what's on the booklist"
- "where am I in X"
- "how much did I read this week"

## Record format

One line per reading session, `1-data/2026-10.jsonl`:

```json
{"date":"2026-10-14","title":"Sapiens","pages":28,"minutes":40,"note":"cognitive revolution","mood":"absorbed"}
```

| field | required | meaning |
|---|---|---|
| `date` | yes | the day you read, not the day you logged it |
| `title` | yes | full title, not an abbreviation |
| `pages` | | use `loc` for ebooks |
| `minutes` | | an estimate is fine |
| `note` | | one sentence: what you read or what it made you think |
| `mood` | | absorbed / drifting / grinding |

## Rules

- Three books in one day means three lines, not one.
- Rereading a book adds a line; `date` separates them.
- Abandoning a book is one line with `pages: 0` and note "abandoned" — earlier records stay.
- A week starts on Monday.

## How to work

Numbers come from a script under `4-engine/`; the model understands the request and
explains the result. It never does the arithmetic itself.

```bash
python 4-engine/report.py --week
python 4-engine/report.py --week --field pages
```

|---|---|
