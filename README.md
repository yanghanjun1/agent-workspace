# agent-workspace

**The bot changes. The workspace doesn't.**

A workspace is a directory your agent opens: one small identity file, one manual per
life-domain, and two logs that keep the thing from rotting. Domains are generated by the
agent, not hand-written by you; conformance is checked by an assertion, not by vibes.

> commit by commit — read the history, it is the point.
